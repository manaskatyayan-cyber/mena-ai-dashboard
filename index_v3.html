    When it broke: Google Ads conversions vs real Paid Search orders, per day

    Meta "Results" = different things per campaign

    CampaignResult types reported (days)

    How to fix it

    1. Agree one conversion definition. "Conversion" = completed purchase (order ID + revenue). Set it as the only primary conversion in Google Ads; demote page views, leads and micro-events to secondary.
    2. Optimise Meta on purchases only. Move conversion campaigns to the Purchase event, report "Results" per objective, never summed across campaigns.
    3. Deduplicate and pass order IDs. Send transaction ID with every purchase tag (site, GA, Google Ads, Meta Pixel + Conversions API) so one order is counted once.
    4. Fix the site tagging. Cart-add firing more than cart page views, shop views above total page views and orders above payment views point to double-firing or mis-scoped tags - run a tag audit (GTM preview / debug) on the checkout flow.
    5. Label the data. Add the missing dimension that separates the two Site Data blocks (market/device/site) and a channel for the unassigned rows.
    6. Reconcile daily. Platform purchases vs backend orders by channel, with a tolerance band (e.g. ±10-15%). Anything outside triggers an alert (tab 7).
